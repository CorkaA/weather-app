# WeatherApp

Верстка страницы погодного приложения по макету из Figma.

- Ник — Corka 
- Имя — Анна

## Технологии
- HTML5 (семантическая верстка)
- CSS3 (БЭМ, Flexbox, CSS Grid)
- JavaScript (Vanilla JS, работа с DOM)

## Структура проекта
```text
project/
├── public/
│   └── bg.jpg          # Фоновое изображение
├── index.html          # Разметка страницы
├── style.css           # Стили
├── script.js           # Логика взаимодействия
└── README.md           # Документация
```

## Реализованный функционал
Верстка
- Фон: Изображение bg.jpg из папки public растягивается на весь экран, не теряет пропорции и не скроллится вместе с контентом.
- Центрирование: Контентная часть расположена по центру экрана. Минимальная ширина экрана — 1280px.
- Скролл: При высоте окна браузера меньше контентной части появляется вертикальная прокрутка.
- БЭМ: Все классы именованы по методологии БЭМ.

Компоненты
- Хедер: Логотип (SVG) и поле поиска.
- Блок текущей погоды: Город, дата, время, температура, описание и ощущаемая температура (данные заполнены из макета).
- Сетка карточек: 6 карточек-заглушек для прогноза (CSS Grid).

Поле поиска (Search)
Реализованы все состояния из макета:
- Default — пустое поле с иконкой лупы.
- Hover — изменение фона при наведении.
- Active — подсветка поля при фокусе.
- Typing / Filled — при вводе текста иконка лупы скрывается, появляется иконка очистки.
- Hover Delete — крестик окрашивается в цвет темнее при наведении.

Очистка: Клик по крестику очищает поле и возвращает фокус в инпут.

JavaScript
- Текст, введенный в поле поиска, выводится в console.log при каждом нажатии клавиши.
- Обработка клика по кнопке очистки.
- Переключение классов состояний (is-active, is-filled) на контейнере поиска.
