## Технологии
- HTML5 (семантическая верстка)
- CSS3 (БЭМ, Flexbox, CSS Grid)
- JavaScript (Vanilla JS, работа с DOM)

## Реализованный функционал
Верстка
- Фон: Изображение bg.jpg из папки public растягивается на весь экран (background-size: cover), не теряет пропорции и не скроллится вместе с контентом (background-attachment: fixed).
- Центрирование: Контентная часть расположена по центру экрана по горизонтали и вертикали (min-height: 100vh; display: flex; justify-content: center; align-items: center;). 
- Минимальная ширина экрана — 1280px.
- Адаптация по высоте: При высоте окна браузера меньше контентной части появляется вертикальная прокрутка благодаря использованию min-height.
- БЭМ: Все классы именованы по методологии БЭМ. Блоки (header, search, current-weather, forecast, slider, footer) являются самостоятельными сущностями.
- CSS-переменные: Цвета, отступы и размеры шрифтов вынесены в :root для удобства поддержки и переиспользования.
- Доступность: У кнопок и поля ввода добавлены aria-label для скринридеров. Декоративные SVG-иконки скрыты через aria-hidden="true".

Компоненты
- Хедер: Логотип (SVG), обернутый в ссылку и поле поиска.
- Блок текущей погоды: Главный заголовок страницы размечен через <h1> (город). Дата и время обернуты в семантический тег <time> с атрибутом datetime.
- Сетка карточек: 6 карточек-заглушек для прогноза (CSS Grid).

Поле поиска (Search)
Реализованы все состояния из макета:
- Default — пустое поле с иконкой лупы.
- Hover — изменение фона при наведении.
- Active — подсветка поля при фокусе, крестик очистки появляется при клике на поле.
- Typing / Filled — при вводе текста иконка лупы скрывается, появляется иконка очистки.
- Hover Delete — крестик окрашивается в цвет темнее при наведении.
- Font — поле ввода наследует основной шрифт.

JavaScript
- Текст, введенный в поле поиска, выводится в console.log при каждом нажатии клавиши.
- Обработка клика по кнопке очистки: сброс значения, снятие класса is-filled и возврат фокуса в инпут.
- Переключение классов состояний (is-active, is-filled) на контейнере поиска.
